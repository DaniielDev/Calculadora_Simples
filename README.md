# Calculadora_Simples
O que este mini projeto faz?
- Este é um projeto de uma calculadora simples.
- Realiza cálculos de soma, multiplicação, divisão e subtração.

Qual a finalidade do projeto?
- Colocar em prática alguns dos meus conhecimentos adquiridos em java.
